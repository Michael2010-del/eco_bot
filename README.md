🌿 **Eco Helper Telegram Bot**
Python • Telebot • Экология • Переработка отходов

## 📖 О проекте
Экологический Telegram-бот, созданный для просвещения пользователей в вопросах защиты окружающей среды и правильной утилизации отходов. Бот предоставляет практические советы по экологичному образу жизни, интересные факты о состоянии планеты и подробные инструкции по сортировке различных видов мусора.

## ✨ Основные возможности
- **💡 Экосоветы** - 50+ практических рекомендаций для повседневной жизни
- **🌍 Экологические факты** - научные данные о состоянии планеты
- **🗑️ Гид по отходам** - подробные инструкции по 7 типам мусора
- **🗺️ Карта переработки** - ссылка на интерактивную карту пунктов приёма
- **📚 Образовательный подход** - структурированная информация по категориям
- **🔋 Опасные отходы** - особый акцент на батарейках и электронике

## 🚀 Установка и запуск
### Требования:
- Python 3.8+
- Библиотеки: `pytelegrambotapi`
- Токен бота от [@BotFather](https://t.me/BotFather)

### Шаги установки:
1. **Создайте проект:**
```bash
mkdir eco_bot && cd eco_bot
```

2. **Установите зависимости:**
```bash
pip install pytelegrambotapi
```

3. **Создайте файл конфигурации:**
```python
# config.py
TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
```

4. **В main.py замените строку:**
```python
# Вместо:
bot = telebot.TeleBot("YOUR TOKEN)
# Используйте:
from config import TOKEN
bot = telebot.TeleBot(TOKEN)
```

5. **Запустите бота:**
```bash
python main.py
```
